# Avify

> Avify is a WhatsApp-first commerce and CRM platform for small and medium-sized businesses (PYMEs) across Latin America. It connects WhatsApp/Instagram/Messenger conversations to inventory, an online store, POS, payments, shipping and electronic invoicing. Developers integrate via a GraphQL API and a REST API (base path /api/v1), authenticated with an api-key header.

## APIs
- [Avify GraphQL API](https://api.avify.com/graphql): Primary developer API — products, inventory, store locations, carts, orders, payment methods.
- [Avify REST API v1](https://api.avify.com/api/v1): Connectivity test and product media upload.
- [GraphQL Sandbox](https://sandboxapi.avify.co/graphql): Hosted sandbox for testing.

- [Orders V1](https://avify.com/docs/ordenes-v1-api): The OrderV1 object model.
- [Webhooks](https://avify.com/docs/webhooks-api): create_order and update_order events (OrderV1).
- [Getting Started](https://avify.com/docs/guia-inicio-rapido): Quick-start guide.
